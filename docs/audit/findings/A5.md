## Tóm tắt

Bảo mật file ở backend khá chắc: tên skill qua regex chặt, symlink/junction bị từ chối khi ghi/xóa, import không đi theo link, có kiểm tra origin cục bộ. Lỗi dữ liệu thật nằm ở thao tác ghi: import có overwrite xóa đích trước khi copy (mất cả hai nếu lỗi, test đỏ chứng minh) và `save_skill` không nguyên tử. Phía UI có hai lỗi nên sửa trước: race `openEditor` có thể lưu nội dung skill A vào skill B, và SkillPicker tính skill lỗi định dạng là đã tick (ẩn nhưng vẫn ghi vào allow-list), cùng nhãn "Lỗi định dạng" sai cho skill đã xóa. Trạng thái loading/lỗi/trống ở cả hai nơi chưa đủ (lỗi tải trông như rỗng, không retry, không hint, không aria-live), lỗi API hiển thị chuỗi thô thay vì theo mã. Bàn phím, độ tương phản, 375px chưa đo bằng Playwright nên ở mức SUSPECTED. Mỗi lỗi P1/P2 cần test hồi quy đỏ trước khi sửa.
